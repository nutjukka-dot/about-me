# Jakkapop — Personal Portfolio

A responsive, green-toned personal portfolio for Jakkapop (Nut), featuring a 3D-inspired interactive orb, subtle motion, and Thai-first content.

## Run locally

Open `index.html` in a modern browser. No build step is required.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Stack

- HTML, CSS, vanilla JavaScript
- CSS 3D transforms and pointer interaction
- Intersection Observer for scroll reveals
- Google Fonts (Prompt, IBM Plex Mono)

The page respects `prefers-reduced-motion` and includes a mobile navigation layout.
